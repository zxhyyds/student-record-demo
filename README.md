# 手机端学籍档案界面演示

根据提供的截图制作的响应式静态页面，可通过 GitHub Pages 在手机上访问。

**非官方网站。全部资料仅用于界面演示，不作为学籍或学历证明。** 页面没有登录、后端接口或真实验证报告。仓库不包含原始截图或真实个人资料。

## 在线编辑

1. 打开页面，点击左上角“编辑”。
2. 选择录取照片、学历照片；支持预览、更换、移除。JPG、PNG、WebP 每张不超过 20 MB，浏览器会压缩后保存。不能读取的 HEIC 图片需先转为 JPG 或 PNG。
3. 修改姓名、学校、专业、日期等资料；详情里的字段名称、照片标题、页面标题、按钮和底部文字也可修改。顶部非官方演示标识固定保留。
4. 点击“保存并展示”。刷新或关闭后重新打开，同一浏览器仍保留资料。取消会放弃本次修改。“恢复初始内容”也需点击保存后才生效。

照片和文字仅存于当前域名下的浏览器 localStorage，不上传至 GitHub 或其他服务器。换设备、换浏览器或清除网站数据后不会保留；无痕窗口关闭后也可能丢失。不适合作为唯一的资料备份。存储失败时保留编辑草稿并显示提示。

## 文件

- `index.html`：页面内容与演示资料，可直接编辑。
- `styles.css`：手机与桌面布局。
- `app.js`：文字与图片编辑、当前浏览器保存、演示说明弹窗。
- `favicon.svg`：网站图标。
- `.nojekyll`：以静态文件发布。

## 本地预览

在此目录运行 `python -m http.server 8768`，再访问 `http://localhost:8768`；也可以直接打开 `index.html`。

## 发布与更新

GitHub 仓库 Settings → Pages，选择从 `main` 分支的根目录发布。修改文件并推送到 `main` 后，GitHub Pages 自动更新。

布局包含截图中的绿色信息卡、照片占位、学籍详情和底部按钮。手机的状态栏、浏览器地址栏与前进后退栏由浏览器自身显示。按钮打开明确标注的演示说明，并提供学信网官方网站入口。
